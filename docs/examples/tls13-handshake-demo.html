TLS 1.3 握手：一次往返建立加密

相比 TLS 1.2 的 2-RTT，TLS 1.3 只要 1-RTT · 0-RTT 恢复模式可更快

💻

Client 客户端

browser:443 →

🖥️

Server 服务器

← :443 nginx

① ClientHello (key_share) 支持 TLS_AES_128_GCM · x25519
── ① 客户端直接带上 ECDHE 公钥 ──
② ServerHello + Cert + Finished 证书链：*.example.com（Let's Encrypt）
③ Finished ✔ 密钥一致 握手完成，密钥就绪
🔒④ APPLICATION DATA · AES-256-GCM 加密隧道已建立（1-RTT）🔒

① ClientHello

客户端直接发送密码套件 + ECDHE 公钥（key_share），把 1.2 的两步并成一步。

② ServerHello + Certificate

服务器选定套件、回传 ECDHE 公钥与证书链，双方各自推出相同会话密钥。

③ Finished 双向校验

用会话密钥加密握手摘要互验——中间人篡改任何一步都会在这里暴露。

④ Application Data

之后所有 HTTP/2、HTTP/3 报文都在 AEAD 对称加密隧道中传输。
