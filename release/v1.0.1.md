## 修复

- **症状**：在 KCoder GUI 切换 dsh-animations 的 Agent 预设失败，报
  `failed to apply loader entry persona (@deepseek-ai/dsh-persona): invalid config: - $.prefix missing required value`。
- **根因**：`presets/agent.cordis.yml` 用 `text:`，而 `@deepseek-ai/dsh-persona` 的
  `Config` schema 收 `prefix: string (required)`。上游升级 schema 未做兼容 shim。
- **修后行为**：persona config `text:` → `prefix:` + 加 schema 注释钉住字段名。
- 同型 bug 影响 dsh-video-generator / dsh-super-ppts，同期修复并各自发版。

## 兼容性与升级说明

- 无后端/客户端/API 破坏性变化；仅 preset YAML 字段名修正。
- 升级方式：`dsh plugin --profile web add dsh-animations`（插件管理检测到新版本后手动更新）。

## 验证

- preset YAML 字段对齐 `@deepseek-ai/dsh-persona` 的 `Config` schema 字段名；
  安装目录 `<DSH_HOME>/.agent-presets/dsh-animations/agent.cordis.yml` 已同步。
