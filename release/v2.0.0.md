# v2.0.0 — 移除 Web GUI「动效技能库」工作台，收敛为纯 host 插件（破坏性变更）

## 版本信息

| 项 | 值 |
|---|---|
| 版本 | 2.0.0 |
| 日期 | 2026-10-19 |
| tag | v2.0.0 |
| 主题 | 整块退役 client 半边：左栏工作台（图标入口 + 主面板 + 会话桥）移除，只保留 Agent 后台调用能力 |
| 发布渠道 | npm registry；GitHub tag；dsh-plugins 镜像仓 |

## 一、破坏性变更：Web GUI 工作台整块移除

- **移除交付物**：`lib/client.js`（612 行手维护 `__ModuleLoader__` 扩展）及 `lib/` 目录；
  随之消失的是左侧栏 `sidebar.panellist` 图标入口（id `anim-panel`）与 `main` keyed
  主面板（工作区下拉 / 技能卡片单选 / 需求输入 / 一键「发送到对话」），以及面板
  依赖的会话桥 v4、locale 双词典与面板样式注入。
- **manifest 收口**：`exports["./client"]`、`files` 白名单的 `lib/client.js`、
  `dsh.client` / `qilin.client`（bundle + 4 引擎包 inject）、以及 4 条
  `@deepseek-ai/dsh-client-*` 的 `peerDependencies` 与 `peerDependenciesMeta` 全部删除。
- **影响面**：升级后不再有任何 Web GUI UI——不占左侧栏、不挂主面板、不注入样式，
  也不再有「发送到对话」的跨工作区投递入口。

## 二、保留不变：host 半边零改动

- `entry.js` 逐字节未动：`inject = ['skills', 'systemPrompt']`，激活即读
  `skills/manifest.json` 注册 **8 个 runtime skill**（frontmatter 剥离、
  `resourceBase` 指向技能目录），并向 systemPrompt 注入能力通告 section（order 207）；
- 双通道 `bundle.patch`（`dsh` / `qilin`）仍指向同一份 `cordis.patch.yml`；
- 兼容门不变：`@deepseek-ai/dsh` peer 仍为 `>=0.1.0-rc.5 <1.0.0` 且 optional。
- 配置开关 `enabled` / `announceToAgent` 语义不变。

## 三、升级说明

- 语义化版本按破坏性变更抬至 **2.0.0**（1.2.4 → 2.0.0）；升级即替换包体，无需迁移；
- 原先依赖左侧栏工作台投递的用法，改为在会话中直接描述需求
  （如「用 ppt-animation 做一份 HTTP 协议演示」），Agent 读对应 SKILL.md 后生成
  单文件 HTML，产物落在当前工作目录；
- 对只使用 8 个技能与能力通告的用户，行为与升级前完全一致。

## 四、验证

- `node scripts/smoke-plugin.mjs` **全绿**（60 项）：清单一致性、`entry.js` apply 全流程
  （8 skill + 1 通告 + disposer 回收 + `enabled:false` / `announceToAgent:false` 短路）、
  通告覆盖全部技能名、patch id 对账，以及新增的**纯 host 契约哨兵**——
  双通道无 client 声明、无 `./client` 导出、`files` 无 `lib/client.js`、磁盘无 `lib/`、
  peer 仅 `@deepseek-ai/dsh` 且 optional、发版记录对账；
- `node scripts/sync-to-dsh-plugins.mjs --check` 镜像对账零差异。

## 五、残缺项说明

- `package.json` 中 `"release": "node scripts/release/update-readme.mjs"` 指向的脚本文件
  在本仓并不存在（历史遗留的死引用），本次发布一并删除，避免 `npm run release`
  报 ENOENT。
