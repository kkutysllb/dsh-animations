### 核实稳定（免改）

- host 两服务面：`systemPrompt.section({name, order, text})`、`ctx.skills.register(SkillRegistration)`（`{name, description, whenToUse?, source, content, resourceBase?}` 形状未变）；
- client 七服务名 `slots / locale / sessions / uiWorkspace / workspaces / layout / conversation`（根 `conversation` = ConversationController 单例，`input` 为 SessionInputResolver）；
- `conversation.input.for(actx).setDraft/submit`（`SessionInput` 保留；`uiConversation.fillDraft` 同口径 = `binding(id).ctx` → `input.for`）；
- slot 三注册面全兼容：`sidebar.panellist`（id/order/label/locale，owner props `{size, active}`）与 `main` keyed（key=anim-panel，key 域开放）；
- 工作区菜单：`useWorkspaces: SnapshotSelectorHook<WorkspaceSnapshot>`（`{items, phase:'pending'|'ready', …}`，`WorkspaceView{workspaceId,title,path,sessionIds}`）；
- `layout.selectPanel(null)`、`sessions.create(opts?)`、`ctx.locale.register/bind`、`ctx.slots.inject/register`、`ctx.effect`。

0.1.7 系列破坏面本插件**均未消费**：`turnTail` chain→list、`conversation.session.header.leading`→`shell.leading`、`settingsScope`→`configForms`、`ToolCallOwnerProps` 三态化、`TranscriptViewMode` 四值化、ui-primitives 图标改名。

## 二、变更与修复

- **会话桥 v4**（`lib/client.js`）：
  - `currentSessionId`：当前会话判定改 `retainedBy.mainView` 口径（旧宿主 `list.current` 兜底）；
  - 新建会话选中改 `uiWorkspace.openSession(target)`（旧宿主 `sessions.open` 兜底）；
  - 递送期经 `sessions.using(id, {source:'dsh-animations'}, op)` 持引用（0.1.7 `scope(id)` 只借已 retain 的 generation；using 缺席的旧宿主直接递送）；
  - 输入壳解析对齐 `uiConversation.fillDraft` 口径（`binding(id).ctx` → `conversation.input.for(actx)`，`actx.conversation` 旧路径兜底），并新增**挂载重试**（6×200ms，openSession 后输入壳迟到位仍可送达）；
  - `openWorkspace(ws, beforeOpen)` 同步落点 id，按落点会话递送；
  - 结果语义不变：`'submitted' | 'copied' | 'none'`；**无 submit 或任一步失败绝不假报 submitted**。
- **修复「发送到对话」在 0.1.7 宿主上恒降级剪贴板、从不自动提交**：
  - 症状：工作台点「发送到对话」提示「已复制到剪贴板」，用户须手动粘贴回车；
  - 根因：0.1.7 契约层变更——`SessionListState.current` 删除 + `sessions.open()` 删除 + `sessions.scope(id)` 收紧（详见审计表 1/2）；
  - 修后行为：v4 桥恢复「落草稿 → 自动提交」闭环；旧宿主（0.1.5–0.1.6）保留双世代软降级。
- **manifest 契约收口**（`package.json`，`dsh`/`qilin` 双通道同改）：
  - `client.inject` 移除死包 `@deepseek-ai/dsh-client-runtime`，冻结为 4 引擎包（`dsh-client-locale` / `ui-slots` / `ui-conversation` / `ui-workspace`）；
  - 新增 `peerDependencies` 5 条 `>=0.1.0-rc.5 <0.2.0`（含 prerelease 比较器）+ `peerDependenciesMeta` 全部 `optional`。
- **冒烟**（`scripts/smoke-plugin.mjs`）：新增 0.1.7 契约层哨兵（死包 / inject 冻结清单 / peer 三则 / 发版记录对账）与会话桥 v4 断言（mainView 判定、fillDraft 同口径壳解析、setDraft→submit 闭环、无 submit 绝不报 submitted、挂载重试、using 持引用、create+openSession、openWorkspace-beforeOpen 落点、旧宿主面回归）。

### peer 必须 optional 的实测依据（2026-09-25，pnpm 11.23 最小复现，与 dsh-super-ppts 1.4.3 同批）

- 非 optional 的宽范围 peer（`>=0.1.0-rc.5 <0.2.0`）会让 pnpm peer 自动安装解析到同 tuple 预发布 `0.1.0-rc.8`，把**整棵引擎树（448 包）**静默拉进用户 profile——比报错更糟的静默污染；
- `peerDependenciesMeta.optional: true` 后零拉取；而 0.1.7 兼容门只读 `peerDependencies` 不看 meta ⇒ **门禁照常强制、安装面零污染**；
- 范围 `>=0.1.0-rc.5 <0.2.0`：覆盖 0.1.5→0.1.7-rc.x 及未来 0.1.x，0.2.x 起被门禁拒绝（未验证大版本不默认放行，届时随新版本平移范围）。

## 三、兼容性与升级说明

- **目标宿主**：DSH / KCoder / QiLin **0.1.7 系列**（rc.1/rc.2）；旧宿主（0.1.5–0.1.6）走双世代降级路径（`list.current` / `sessions.open` / `actx.conversation` 直读）。
- **契约声明**：manifest 新增 `peerDependencies`（5 条，`>=0.1.0-rc.5 <0.2.0`）。0.1.7 起安装/启动按该范围强校验（不满足被拒，需 `dsh plugin allow-version` 精确豁免）。
- **接口契约**：8 个技能名、SKILL.md 工作流、能力通告文本、工作台交互、`cordis.patch.yml` 行 id **全部不变**；升级即替换包体（`dsh plugin add` / 插件管理更新），无需迁移。
- **slot 面**：`sidebar.panellist` / `main` 两注册与 0.1.7 槽位契约兼容（本轮仅注释口径对齐，无行为改动）。
