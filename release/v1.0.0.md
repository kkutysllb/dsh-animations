## 新增

**标准 DSH 插件形态**

- `package.json` dsh bundle manifest（`dsh.bundle.patch` / files 白名单 / smoke·sync·prepack 脚本），零构建链、零 npm 依赖，`dsh plugin --profile web add` 直装。
- `cordis.patch.yml` bundle 层注册（id: `dsh-animations`）。
- `entry.js` 胶水插件：激活时按 `skills/manifest.json` 注册 8 个 runtime skill（`resourceBase` 指向技能目录，正文相对资产可解析）、向 systemPrompt 注入能力通告 section（order 207，`announceToAgent` 可关）、幂等安装「动画演示专家」Agent 预设到 `~/.dsh/.agent-presets/dsh-animations/`。
- `presets/`：「动画演示专家」Agent 预设（persona 八形态路由 + 标准 infra 行）。
- `skills/manifest.json`：技能注册清单（单一事实源，与 SKILL.md frontmatter 由 smoke 对账；`scholar-notes` ↔「学霸笔记」别名放行）。

**质量与发布工具**

- `scripts/smoke-plugin.mjs`：零依赖冒烟（清单一致性 / apply 全流程 / 通告覆盖 / patch 对账 / enabled·announceToAgent 开关），47 项检查。
- `scripts/sync-to-dsh-plugins.mjs`：真源 → dsh-plugins 镜像同步（`--check` 对账断言），镜像排除 gitignored 产物（`output/`、`node_modules`）。
- 三级分发链就位：独立仓（真源）→ dsh-plugins（镜像收纳）→ KCoder `bundle/`（随包分发）。

**案例示例展示（docs/）**

- 4 个新创作案例页：`docs/examples/llm-work-ppt-demo.html`（ppt-animation 翻页演示）、`rag-flowchart-demo.html`（flowchart）、`tls13-handshake-demo.html`（network-protocol-viz）、`sql-injection-note-demo.html`（scholar-notes）。
- 4 张模板/成片截图：dynamic-archify（QClaw 架构）、card-theater（IPsec Coverflow）、video-shot-demos（电影化播放器）、phone-ui-demos（可学分镜表）；archify 案例页随 `docs/examples/qclaw-architecture-demo.html` 分发。
- `docs/screenshots/`：8 技能全覆盖示例图（1920×1080），README 全部改为仓内引用。

**文档**
